# 令和8年度介護事業経営実態調査の結果（案）：全サービス平均の収支差率は4.3%

## 要点
- 令和8年度介護事業経営実態調査の結果（案）で、令和7年度決算の全サービス平均の収支差率は4.3%（税引前・物価高騰対策関連補助金等を含まない）です。令和6年度決算（令和7年度概況調査）の4.7%から▲0.4ポイントでした。
- 介護事業経営調査委員会（令和8年11月16日）と社保審・介護給付費分科会（11月20日）の資料に載った**「案」の段階の結果**です。
- 当てはまる事業所は注意：通所介護（収支差率1.4%、前年度比▲4.8ポイント）や居宅介護支援（4.6%、▲1.6ポイント）は下がっています。人件費に回せる余力は、サービスによってかなり違います。

## 対象
すべての介護サービスの事業所。サービス別に数字が違うため、自社のサービスの行を確認してください。

## 何が起きたか
- 令和8年11月16日の第45回介護事業経営調査委員会に、令和8年度介護事業経営実態調査の結果（案）が資料として出ました。11月20日の第276回介護給付費分科会にも、同じ内容の資料が出ました。
- 調査は、各サービス施設・事業所の経営状況を把握し、次期介護保険制度の改正及び介護報酬の改定に必要な基礎資料を得るものとされています。調査時期は令和8年5月、方法は郵送とオンラインです。調査客体数は34,500、有効回答数は14,117（有効回答率40.9%）です。令和7年度決算（改定後2年目の1年分）の収支を調べています。
- 全サービス平均の収支差率は4.3%（令和6年度決算は4.7%、▲0.4ポイント）です。物価高騰対策関連補助金等を含めた税引前では4.9%（前年度4.8%、＋0.1ポイント）です。

**サービス別の収支差率（税引前・補助金等を含まない）**

| サービス | 令和6年度決算 | 令和7年度決算 | 増減 |
|---|---|---|---|
| 介護老人福祉施設 | 1.4% | 0.7% | ▲0.7 |
| 介護老人保健施設 | 0.6% | 0.8% | ＋0.2 |
| 介護医療院 | 3.5% | 2.3% | ▲1.2 |
| 訪問介護 | 9.6% | 11.3% | ＋1.7 |
| 訪問看護 | 10.3% | 8.5% | ▲1.8 |
| 通所介護 | 6.2% | 1.4% | ▲4.8 |
| 特定施設入居者生活介護 | 5.3% | 6.4% | ＋1.1 |
| 居宅介護支援 | 6.2% | 4.6% | ▲1.6 |
| 地域密着型通所介護 | 6.3% | 6.8% | ＋0.5 |
| 小規模多機能型居宅介護 | 6.0% | 7.0% | ＋1.0 |
| 認知症対応型共同生活介護 | 4.9% | 3.8% | ▲1.1 |

増減の単位はポイントです。令和6年度決算は令和7年度介護事業経営概況調査の結果です。収支差率は、平均値と中央値で差があります（令和7年度決算：訪問介護は平均11.3%・中央値7.4%、介護老人福祉施設は平均0.7%・中央値0.3%）。

**赤字の事業所の割合（令和7年度決算。令和6年度決算は括弧内）**
- 全サービス：38.3%（37.5%）
- 介護老人福祉施設：49.1%（44.3%）
- 通所介護：45.7%（37.4%）
- 居宅介護支援：46.2%（40.0%）
- 訪問介護：32.2%（35.1%）

**費用構造（資料の「介護サービス全体」。1施設・事業所あたり、月、加重平均）**
- 収入：令和6年度647万円 → 令和7年度657万円（＋1.5%）
- 費用：618万円 → 629万円（＋1.8%）。うち人件費は398万円 → 402万円（＋1.0%）
- 収支差：28万円 → 27万円（▲3.2%）

**人材確保に関わる費用（令和7年度決算。人材紹介手数料の計上がなかった事業所も含む。対収入割合）**
- 人材紹介手数料：介護老人福祉施設0.3%、訪問介護0.2%、通所介護0.4%、認知症対応型共同生活介護0.6%、訪問看護0.8%。
- 派遣委託費：訪問介護1.1%、介護老人福祉施設1.6%、訪問入浴介護6.5%、小規模多機能型居宅介護1.6%。

## 採用・定着への影響（編集部の見立て）
- 収支差率は事業所の平均値です。自社の賃上げの余力が同じとは限りません。ただ、サービスによって「人件費にどこまで回せるか」の目安が違うことは、採用条件を決めるときの前提になります。
- 通所介護や居宅介護支援のように収支差率が下がったサービスでは、賃金以外（休日、働き方、研修）で条件を伝える工夫が、比べられたときに効いてくる可能性があります。
- 人材紹介手数料や派遣委託費が収入に占める割合は、サービスによって違います。自社の採用経路ごとの費用を整理する際の比較の目安になります。

## 数字で見る
資料の「介護サービス全体」の費用構造（令和7年度）に、仮定の賃上げを当てはめた試算です。

| 項目 | 値 | 種類 |
|---|---|---|
| 収入（月） | 657万円 | 資料の数字（加重平均、補助金等を含まない） |
| 人件費（月） | 402万円 | 資料の数字 |
| 収支差（月） | 27万円 | 資料の数字 |
| 人件費の増加率 | 1% | **仮定** |
| 収入 | 変わらない | **仮定** |

計算：
- 人件費の1%：402万円 × 1% ＝ 約4.02万円（月）
- 収支差：27万円 − 4.02万円 ＝ 約22.98万円（月）
- 収入に対する割合：4.02万円 ÷ 657万円 ≒ 約0.61ポイント

読み方と注意：
- 収入が変わらないまま人件費だけが1%増えると、この平均的な事例では収支差が月約4万円、約0.6ポイント分減る計算です。
- 実際には、加算の算定や利用者数の変化で収入も動きます。事業所の規模・サービス・人件費の割合で結果は変わります。自社の数字で同じ計算をしてみてください。
- 自社で計算する式：自社の月の人件費 × 賃上げ率 ÷ 自社の月の収入 ＝ 収入に対する負担増の割合です。

## こんな事業所は注意
- 通所介護・居宅介護支援・介護老人福祉施設の事業所 → 令和7年度決算で収支差率が前年度より下がり、赤字の事業所の割合が上がっています。人件費の見直しや採用条件の変更は、自社の収支の数字で確かめてからにしてください。
- 人材紹介会社や派遣を多く使っている事業所 → 手数料や委託費が収入に占める割合を、上の資料の数字と比べてみてください。
