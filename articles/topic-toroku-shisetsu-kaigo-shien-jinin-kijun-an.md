# 新設の「登録施設介護支援」、人員基準の案

## 要点
- 登録制の対象となる住宅型有料老人ホームの入居者のケアプランを作る新しいサービス「登録施設介護支援」について、ケアマネに加えて「地域生活相談員」を1人以上置く人員基準の案が出ました。地域生活相談員はケアマネとの兼務を認める案です。
- 2026-10-28の第272回介護給付費分科会で厚労省が示した**案**で、まだ決まっていません。
- 当てはまる事業所は注意：住宅型有料老人ホームの入居者を担当している居宅介護支援事業所は、新しいサービスの基準・報酬・利用者負担の受け取りに対応することになりそうです。

## 対象
居宅介護支援事業所・介護予防支援事業所（地域包括支援センターを含む）のうち、登録制の対象となる住宅型有料老人ホームの入居者を担当している、またはこれから担当する事業所。

## 何が起きたか
- 社会福祉法等の一部を改正する法律（令和8年法律第51号）で、有料老人ホームの登録制とあわせて、入居者のケアプラン作成と地域とのつながりの支援をまとめて行う「登録施設介護支援」「登録施設介護予防支援」が新しく設けられました。ホームとケアマネの独立性を保つことがねらいです。
- 法律では、施行のときに居宅介護支援の指定を受けている事業者は、施行日から6年を超えない範囲で政令で定める日まで、登録施設介護支援の指定を受けたものとみなされます（別に申し出た場合を除く）。
- 第272回分科会で厚労省は、基準と報酬について次の案を示しました。
  - 人員：居宅介護支援と同じくケアマネを常勤で1人以上（利用者44人にケアマネ1人が基準。ケアプランデータ連携システムを使う場合は49人に1人）。加えて地域生活相談員を1人以上置き、ケアマネとの兼務を認める。
  - 地域生活相談員を別に置く場合の資格：ケアマネ、または社会福祉主事などの資格を持つ人。
  - 管理者：居宅介護支援と同じとする。資料の基準案では「実務経験5年以上の常勤専従のケアマネ」と書かれています。
  - 人員の数え方：あわせて行う居宅介護支援の人員と一体で数える。
  - 地域生活相談の内容：地域の支援機関や行事などの情報を集めてリスト化し、入居者に紹介して参加を促す、外出の妨げを取り除く調整をする、行き先などをホームと共有する、などの5項目。
  - 運営基準：居宅介護支援に準じつつ、ホームとの密接な連携に努めること、利用者負担額を受け取ること、ホームから得た情報も踏まえてケアプランを作ること、地域生活相談の内容をケアプランに位置付けて記録すること、を加える。
  - 報酬：居宅介護支援と同じ枠組みを前提に、地域生活相談の実施と集合住宅であることを踏まえて設定する。逓減制は居宅介護支援と合わせた利用者数で判断し、低い単価は登録施設介護支援の利用者全体に分散して当てる。
- 利用者負担は、介護付きホームとの均衡から原則1割を求めると、法改正の概要に示されています。
- 施行時期は、有料老人ホームの登録制が始まった後、既存のホームの移行の経過措置期間が終わるころを想定している、と資料に書かれています。

## 採用・定着への影響（編集部の見立て）
- 地域生活相談員をケアマネが兼務できる案なので、すぐに人を増やさなくても対応できる事業所が多そうです。ただ、地域の情報集めや外出の調整は新しい仕事で、ケアマネ1人あたりの負担は増えます。分科会でも、ケアマネの負担が増えて人材確保がさらに難しくなるという懸念が出ています。
- 別に置く場合は社会福祉主事などの資格でもよい案なので、相談員経験のある人をケアマネ以外の職種で採る道も考えられます。
- 利用者負担の請求・受け取りの事務が加わります。事務職員の配置や、請求ソフトの対応も早めに確かめておくと慌てずにすみます。

## 数字で見る
居宅介護支援事業所が住宅型有料老人ホームの入居者も担当している場合の、人員の数え方の例です。

| 項目 | 値 | 種類 |
|---|---|---|
| 常勤ケアマネ | 2人 | **仮定** |
| 居宅介護支援の利用者 | 60人 | **仮定** |
| 登録施設介護支援の利用者（ホーム入居者） | 20人 | **仮定** |
| ケアマネ1人あたりの基準 | 利用者44人 | 案 |
| 地域生活相談員 | ケアマネが兼務 | **仮定**（案では兼務可） |

計算：
- 案では居宅介護支援と一体で数えるので、利用者は60人＋20人＝80人です。
- 80人 ÷ 44人 ≒ 1.82人 → 常勤ケアマネ2人で基準を満たします。
- 地域生活相談員をケアマネが兼務すれば、**追加で採用する人数は0人**です。別に置く場合は**1人**増えます。

読み方と注意：
- 介護予防の利用者の数え方（居宅介護支援では3分の1で数える）や、報酬の逓減制は入れていません。
- 基準を満たすかどうかの目安で、地域生活相談にかかる時間は入れていません。兼務の場合、ケアマネの業務量は増えます。
- 基準・報酬はまだ案です。

## こんな事業所は注意
- 住宅型有料老人ホームに併設・隣接している居宅介護支援事業所 → ホームとの独立性を保つ運営基準が加わる案です。ケアプランにホームの情報をどう反映したかを記録で示せるようにしておく必要がありそうです。
- ケアマネ1人で運営している事業所 → 地域生活相談を兼務すると、その分の時間を見込む必要があります。
- ケアマネ1人あたりの担当件数が、居宅介護支援の逓減制の境目（現行は45件、ケアプランデータ連携システムの活用などで50件）に近い事業所 → 逓減制を居宅介護支援と合わせた利用者数で判断する案なので、ホーム入居者の分を足すと境目を超えることがあります。
